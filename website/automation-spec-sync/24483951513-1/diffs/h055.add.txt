This document defines the preferred MCP-AQL shape for adapter-declared computed fields. Computed fields let adapters expose derived values such as ages, counts, or status booleans without forcing clients or LLMs to reconstruct them from raw records.
Computed fields use the _computed. prefix inside fields :
operation : &quot;get_widget&quot; ,
params : {
widget_id : &quot;widget_123&quot; ,
fields : [ &quot;widget_name&quot; , &quot;_computed.age_days&quot; , &quot;_computed.child_count&quot; ]
The _computed. prefix keeps derived values visibly distinct from persisted fields while still composing with normal field selection.
Computed values are returned under the _computed object:
&quot;success&quot; : true ,
&quot;data&quot; : {
&quot;widget_name&quot; : &quot;Atlas Widget&quot; ,
&quot;_computed&quot; : {
&quot;age_days&quot; : 47 ,
&quot;child_count&quot; : 12
Adapters MAY allow computed fields in other query-language controls when they can evaluate them efficiently:
operation : &quot;search_widgets&quot; ,
filter : {
&quot;_computed.is_stale&quot; : true
sort : {
field : &quot;_computed.age_days&quot; ,
order : &quot;desc&quot;
fields : [ &quot;widget_name&quot; , &quot;_computed.age_days&quot; ]
If an adapter does not support computed-field filtering or sorting, it SHOULD reject those requests clearly instead of silently ignoring them. See Error Codes for the preferred structured error patterns.
Adapters SHOULD advertise computed fields in operation detail metadata:
&quot;computed_fields&quot; : [
&quot;name&quot; : &quot;age_days&quot; ,
&quot;type&quot; : &quot;number&quot; ,
&quot;description&quot; : &quot;Days since creation&quot; ,
&quot;filterable&quot; : true ,
&quot;sortable&quot; : true
&quot;name&quot; : &quot;child_count&quot; ,
&quot;description&quot; : &quot;Number of child widgets&quot; ,
&quot;filterable&quot; : false ,
This gives clients a machine-readable list of the derived values they can ask for, plus whether those values participate in filtering and sorting.
Examples
Time-derived
age_days , time_until_due
child_count , reference_count
Status-derived
is_stale , needs_attention
Size-derived
estimated_tokens , size_human
Field Selection defines the _computed. field path convention.
Collection Querying describes how computed fields interact with filters, sort clauses, and aggregation.
