1. Overview
1.1 Test Pyramid
MCP-AQL adapters follow a standard test pyramid:
What to Test
Individual handlers, parameter validation, response formatting
Integration
Full request pipeline (tool call → response)
Conformance
Protocol compliance against specification
1.2 Test Framework
Examples use Vitest , but any test runner works:
npm install -D vitest
