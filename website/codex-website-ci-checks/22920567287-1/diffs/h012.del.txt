How MCP-AQL Works
A typical request path starts with introspection and ends with operation dispatch through CRUDE/single mode.
1. Discover
Clients call introspect to discover supported operations and parameter contracts at runtime.
2. Route
Operations are routed through semantic endpoints (Create, Read, Update, Delete, Execute) or single-endpoint mode.
3. Enforce
Adapters apply validation, safety, and policy controls before execution (including gatekeeper-style modules).
Example Query Shape
"operation": "introspect",
"params": { "query": "operations" }
