    Recent highlights

    Launch framing clarified

    • README and draft status language now explicitly frame MCP-AQL as a preliminary public draft.
    • Normative versus informative document boundaries were tightened across the spec docs.
    • A coordinated preliminary launch checklist was added for spec and reference-profile messaging.

    Safety model expanded

    • Execution safety loop, safety-dongle model, autonomy evaluator, and out-of-band verification are now documented.
    • Section 9 compliance mappings were expanded to better align informative safety docs to normative requirements.
    • Issue #216 remains the audit record for that alignment work.

    Operational contracts hardened

    • Unknown parameter rejection and structured error examples were added to reduce LLM ambiguity.
    • Canonical operation verbs and session lifecycle guidance were made more explicit.
    • Batch confirmation behavior and payload-size constraints were documented.

    Still open for draft launch

    • #193 MCP capability audit
    • #197 batch size and resource protections
    • #199 structured error surface alignment
