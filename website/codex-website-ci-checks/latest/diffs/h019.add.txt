Reading Order
For newcomers to MCP-AQL:
v1.0.0-draft - Start with the main specification
CRUDE Pattern - Understand the endpoint semantics
Operations - Learn operation design patterns
Introspection - Learn the discovery system
Conformance Testing - Understand conformance requirements
For adapter developers:
Element Type Specification - Declarative schema format
Plugin Interface Contracts - Plugin system contracts
Architecture Overview - Understand adapter structure (in mcpaql-adapter repo)
Development Guide - Implementation walkthrough (in mcpaql-adapter repo)
Gatekeeper - Security implementation

Reference Profile
DollhouseMCP is treated as a practical reference profile for MCP-AQL. It validates feasibility at scale, but protocol authority remains with the normative specification in this repository.
