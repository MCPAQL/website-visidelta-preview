    Launch And Post-Launch Trajectory

    MCP-AQL development is staged across protocol quality, adapter maturity, examples, validator tooling, and ecosystem adoption. This page translates those tracks into a public roadmap view.

    Phase Model

    Phase Focus Public Draft Relevance
    Phase 0 Infrastructure and repository foundations Completed baseline
    Phase 1 Core protocol semantics and endpoint model Core of current public draft
    Phase 2 Quality, conformance, and testing depth Primary in-progress launch hardening
    Phase 3 Adapter specs and interface maturation Reference profile stabilization
    Phase 4+ Advanced features and ecosystem expansion Post-launch expansion track
